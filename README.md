## Instructions for GLM 5.3 Flash

**Read this carefully and complete the full pipeline.**

### Your job

1. Open the folder **`you have to combine/`** in this repository.
2. Inside that folder is (or will be) the archive **`Combine_these.zip`** — extract it.
3. **Combine** everything that is inside that archive into one working **Mobile Godot 4** project (merge scenes, scripts, assets, `project.godot`, export presets, etc. so the game runs as a single project).
4. When you are finished combining, put the final output in the folder **`Result/`**.
5. The final deliverable **must be a `.zip` file** inside `Result/` (for example `Result/NeonHighway_Mobile_Godot4.zip`).
6. Target platform: **Mobile** (Godot 4 — Android/iOS-ready project structure, mobile-friendly settings where applicable).

### Rules

- Do **not** leave loose files only in `you have to combine/` after finishing — the finished package goes in **`Result/`** as a **`.zip`**.
- Keep a valid Godot 4 project layout (`project.godot`, `scenes/`, `scripts/`, `assets/`, etc. as needed).
- If assets conflict, resolve them cleanly (rename or merge) so the project opens in Godot 4 without missing references.
- After creating the zip, push/commit it to this repo under `Result/` if you have git access, or report the full path to the zip.
